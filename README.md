# Phone Number Normalizer

A small JavaScript utility to normalize phone numbers from Germany, Austria, and Switzerland into the international **E.164 format**.

The repo cleans user input and converts national numbers into a standardized international format.

## Features

- Supports Germany (+49)
- Supports Austria (+43)
- Supports Switzerland (+41)
- Converts national numbers to international format
- Removes unnecessary characters like spaces, brackets, or dashes
- Converts `00` prefixes to `+`
